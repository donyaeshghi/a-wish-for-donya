# A Wish for Donya ☾

سایت استاتیک فارسی برای دریافت آرزوهای تولد. صفحه‌ی عمومی فقط فرم ارسال دارد؛ آرزوها در صفحه‌ی عمومی نمایش داده نمی‌شوند و فقط حساب مدیرِ واردشده می‌تواند آن‌ها را بخواند.

## فایل‌ها
- `index.html` و `style.css`: ظاهر سایت
- `app.js`: ارسال آرزو و پنل خصوصی
- `config.example.js`: الگوی اتصال Supabase
- `supabase-setup.sql`: ساخت جدول و قوانین امنیتی دیتابیس

## ۱. ساخت دیتابیس Supabase
1. در https://supabase.com یک پروژه بساز.
2. از بخش **SQL Editor**، محتوای `supabase-setup.sql` را اجرا کن.
3. از **Project Settings → API**، آدرس Project URL و کلید `anon` یا `publishable` را بردار.
4. فایل `config.example.js` را کپی کن و نام کپی را دقیقاً `config.js` بگذار.
5. داخل `config.js` آدرس و کلید عمومی پروژه را جایگزین مقادیر نمونه کن.

**مهم:** کلید `service_role` یا کلید secret را هرگز در فایل‌های سایت قرار نده. کلید عمومی anon/publishable برای مرورگر است و امنیت اطلاعات با RLS کنترل می‌شود.

## ۲. ساخت حساب خصوصی دونیا
1. در Supabase به **Authentication → Users** برو.
2. یک کاربر با ایمیل خودت بساز و برایش رمز عبور تعیین کن.
3. در **Authentication → Providers → Email** ثبت‌نام عمومی (Allow new users to sign up) را خاموش کن؛ فقط حسابی که خودت از داشبورد ساخته‌ای باقی بماند.
4. در **Authentication → URL Configuration**، آدرس سایت GitHub Pages را به Site URL و Redirect URLs اضافه کن. نمونه: `https://USERNAME.github.io/REPOSITORY/`

این پروژه فرض می‌کند تنها حساب احراز هویت‌شده، حساب مدیر خودت است. اگر بعداً کاربران دیگری به پروژه اضافه کردی، سیاست SELECT را محدودتر کن.

## ۳. انتشار در GitHub Pages
1. یک repository جدید در GitHub بساز.
2. فایل‌های پروژه را آپلود کن: `index.html`, `style.css`, `app.js`, `config.js`.
3. از **Settings → Pages**، گزینه‌ی Deploy from a branch را انتخاب کن؛ branch را `main` و folder را `/ (root)` بگذار و Save کن.
4. پس از انتشار، لینک سایت در همان بخش نمایش داده می‌شود.

## ۴. تست امنیت و کارکرد
- در پنجره‌ی ناشناس مرورگر یک آرزوی آزمایشی بفرست.
- مطمئن شو پیام در صفحه‌ی عمومی دیده نمی‌شود.
- به `YOUR-GITHUB-PAGES-URL/#admin` برو و با ایمیل و رمز مدیر وارد شو.
- بررسی کن آرزوی آزمایشی فقط در پنل خصوصی نمایش داده شود.

## نکته‌های مهم
- هر کسی که لینک فرم را داشته باشد می‌تواند آرزو ارسال کند؛ برای سایت عمومی واقعی بهتر است بعداً محدودسازی ارسال، CAPTCHA یا ابزار ضداسپم اضافه شود.
- آرزوها در جدول Supabase ذخیره می‌شوند، نه در مخزن GitHub.
- مخزن GitHub را Public کنی، `config.js` و کلید عمومی در آن قابل مشاهده‌اند؛ این طبیعی است، اما هرگز رمز عبور یا کلید secret را آنجا قرار نده.
